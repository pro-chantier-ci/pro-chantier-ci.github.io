Questions fréquentes

Ce qu'on nous demande souvent.

Ça marche sur iPhone ?

Oui. Les applications s'ouvrent avec un lien dans Safari (iPhone) ou Chrome (Android). Ajoutez-les ensuite à l'écran d'accueil : elles se comportent comme une vraie application.

Faut-il internet sur le chantier ?

Non. Après la première ouverture, l'application fonctionne sans réseau. Vos données restent sur votre téléphone.

Y a-t-il un abonnement ?

Non. Vous payez une seule fois et l'application est à vous. Les mises à jour sont gratuites.

Je change de téléphone, je perds tout ?

Non. Faites « Sauvegarder » dans Mon compte, envoyez le fichier sur votre nouveau téléphone, puis « Restaurer ». Votre code d'activation marche aussi sur le nouveau téléphone.

Je peux essayer avant de payer ?

Oui, chaque application a un essai gratuit avec le même lien. En essai, les documents PDF portent la mention « Démonstration ».

Nous répondons sur WhatsApp, du lundi au samedi. Démonstration possible pour les entreprises.
